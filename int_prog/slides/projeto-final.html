Inteligência artificial

  
IA ajuda a aprender, não escreve o código

  

    
PODE ✅

      
    
        
  • Pedir para explicar uma mensagem de erro
    • 
        
  • Pedir para explicar um conceito (laço, função, CSV)
    • 
        
  • Comparar a sua ideia com outra forma de resolver
    • 
      

    
NÃO PODE ❌

      
    
        
  • Pedir o código pronto ou colar código gerado por IA
    • 
        
  • Gerar o projeto ou funções inteiras
    • 
        
  • Usar IA sem registrar no Diário de IA
    • 
      

  

  

    
Diário de IA (exemplo de uma linha)

Pergunta: "o que significa KeyError: 'preco'?"
Aprendi: o dicionário não tem essa chave;
corrigi o nome no cadastro e testei de novo.

    
Se você não consegue explicar na entrevista, não é seu. Código de IA copiado vale zero.
