A ideia central

Computador, celular, pen drive ou nuvem: para escrever ou ler, o Python só precisa do nome do arquivo. O resto é com o sistema.

Variável ou arquivo?

Variável

Mora na memória do programa. Quando o programa fecha, ela some.

nome = "Ana"

Arquivo

Mora no armazenamento do dispositivo. Continua lá depois que o programa fecha.

anotacoes.txt

A variável é o quadro branco. O arquivo é o caderno.

Texto · escrever

Escrevendo em um arquivo

with open("anotacoes.txt", "w") as arq:

arq.write("Olá, arquivo!\n")

arq.write("Segunda linha\n")

Três etapas

1. Abrir: open() cria a ponte com o arquivo.

2. Usar: write() grava o texto.

3. Fechar: o with fecha sozinho.

Os três modos de abrir

ModoO que fazComo pensar
“r”Lê o arquivoAbrir o caderno para ler
“w”Escreve e apaga o que haviaComeçar uma folha em branco
“a”Escreve no fim, sem apagarContinuar de onde parou

Cuidado: o modo “w” apaga o conteúdo anterior do arquivo.

Texto · laço

Lendo linha por linha

with open("anotacoes.txt", "r") as arq:

for linha in arq:

Um laço, uma linha

A cada volta do for, a variável linha recebe a próxima linha do arquivo.

strip() tira o enter do final.

CSV · escrever

Gravando a matriz em CSV

import csv

notas = [[7, 8, 9], [6, 5, 8], [10, 9, 9]]

with open("notas.csv", "w", newline="") as arq:

escritor = csv.writer(arq)

for linha in notas:

escritor.writerow(linha)

Como funciona

O laço percorre as linhas da matriz.

writerow grava uma linha por vez.

CSV · ler

Lendo um arquivo CSV

import csv

with open("notas.csv", "r") as arq:

leitor = csv.reader(arq)

for linha in leitor:

print(linha)

Na tela aparece

['7', '8', '9']

['6', '5', '8']

['10', '9', '9']

Atenção: tudo chega como texto. Use int() para fazer contas.

Erros comuns para evitar

FileNotFoundError

O arquivo não existe ou está em outra pasta.

open(..., "w")

O modo “w” apagou o conteúdo anterior. Use “a” para acrescentar.

'7' + '8'

Valores do CSV são texto e dão '78'. Converta com int() antes de somar.
