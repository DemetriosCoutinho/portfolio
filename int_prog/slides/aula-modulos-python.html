A ideia central

Um módulo é uma caixa de ferramentas.

Em vez de fabricar um martelo toda vez que precisa pregar, você pega o martelo da caixa. Um módulo é um arquivo com funções guardadas, prontas para usar quando quiser.

Parte 2 · 20 min

Arquivo 1: ferramentas.py

def saudacao(nome):

return "Olá, " + nome + "!"

def dobro(numero):

return numero * 2

def eh_par(numero):

return numero % 2 == 0

def media(lista):

return sum(lista) / len(lista)

Este arquivo é o módulo.

O nome do módulo é o nome do arquivo, sem o .py. Quatro funções, quatro ferramentas guardadas na caixa.

linha = []

for j in range(1, n + 1):

linha.append(i * j)

matriz.append(linha)

return matriz
