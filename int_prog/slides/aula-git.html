    Mini-projeto
    
      
    Seu arquivo, sua função
    
      
      
        
    • A matriz é sempre o primeiro parâmetro, como na atividade de matrizes.
      • 
        
    • Cada função mora num módulo; main.py usa from modulo import funcao.
      • 
        
    • Remover pelo índice: del lista[i], que não devolve o valor.
      • 
        
    • Exemplo: com dois itens em m, del m[0] deixa só o segundo.
      • 
      
    
    
    
    
    
      
    def remover(inventario, i):
    """Apaga a linha da posicao i. As linhas
    seguintes sobem uma posicao.
    Ex.: m = [["a", 1, "x"], ["b", 2, "y"]]
         remover(m, 0)
         -> m == [["b", 2, "y"]]
    """
    del inventario[i]   # novo
    
      
    antes: [["a", 1, "x"], ["b", 2, "y"]]
    depois de del m[0]: [["b", 2, "y"]]
    
    
    
  
    
  
    Mostre o remover.py do repositório-modelo, com a docstring e o exemplo "Ex.:". A aula 03 mostrou from modulo import funcao como variação do import modulo.
