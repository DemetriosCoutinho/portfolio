# Estudo Dirigido — Forja de Heróis

Atividade de laboratório para a disciplina **Programação Orientada a Objetos**
do 2º Ano de Informática Técnico — IFRN-PF.

## Para o aluno

1. Leia o **caderno-estudo-dirigido.pdf** (ou `.md`) com sua dupla.
2. Instale a dependência: `pip install rich`
3. Abra a pasta `scaffold/lab1-modulos-docstrings/` e siga as instruções da **Aula 1**.
4. Avance de lab em lab nas aulas seguintes.
5. Ao final, entregue no Google Classroom:
   ```
   sobrenome1-sobrenome2-estudo-dirigido.zip
   ├── respostas-sobrenome1-sobrenome2.docx
   └── codigo/
       ├── lab1/
       ├── lab2/
       ├── lab3/
       └── lab4/
   ```

## Para o professor

Consulte o **guia-do-professor.md** para cronograma, gabarito e dicas de mediação.

## Pré-requisitos

- Python 3.10 ou superior
- `pip install rich`

## Estrutura

```
scaffold/
├── lab1-modulos-docstrings/   ← Aula 1: módulos, docstrings
├── lab2-sobrecarga-rich/      ← Aula 2: sobrecarga de operadores, rich
├── lab3-heranca/              ← Aula 3: herança, super(), built-ins
└── lab4-polimorfismo/         ← Aula 4: polimorfismo, arena de batalha
```
