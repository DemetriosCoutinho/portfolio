Outra?proponha ao professor
A ferramenta é a casca, o núcleo é seu.
  • Sem ferramenta nova, um menu no terminal já tira nota máxima de POO
  • Classes de domínio ficam num pacote próprio (dominio/), sem import pygame, flask ou tkinter
  • O framework só cria e chama os seus objetos; o UML descreve o domínio
  • O domínio precisa rodar sozinho no terminal (python -m dominio.demo)
  • Herdar de classe do framework é bem-vindo, mas não conta como herança ou abstração do grupo
Casca: Pygame · Flask · Tkinter · Richjanela, página, botões e desenho

dominio/Personagem, Batalha, Livro, Emprestimo… Python puro
Bônus de até +10 (teto 100)

para ferramenta bem integrada, só com o checklist de POO completo.

=== Entrada 3 ============================================
Data e hora: 2026-12-02, 20:41
Ferramenta e modelo: Claude (Sonnet), conversa nova
Prompt (literal): "Na minha Biblioteca, Aluno e Professor herdam de
Usuario. Por que Emprestimo.registrar() lança AttributeError:
'Aluno' object has no attribute '_nome'? Não quero o código
pronto, só entender o erro."
Resposta (resumo): o __init__ de Aluno não chama super().__init__(),
então Usuario nunca criou _nome.
O que entendi: a subclasse precisa inicializar a superclasse; sem
isso os atributos privados da base não existem.
O que mudei: super().__init__(nome) em dominio/usuario.py
(commit 4f9a1c2). Escrevi à mão; não copiei trecho da resposta.
Como verifiquei: python -m dominio.demo roda e o teste
test_emprestimo.py::test_aluno_guarda_nome passa.
O que descartei: tornar _nome público: quebraria o
encapsulamento que o UML descreve.
=== Entrada 4 (mesmo formato, os 8 campos) ================

Um arquivo por pessoa, diarios/diario_<nome>.txt, versionado no GitHub do grupo.

O que cada entrada precisa ter
  • Data e hora
  • Ferramenta e modelo
  • Prompt literal, sem editar
  • Resposta em resumo
  • O que você entendeu, com as suas palavras
  • O que mudou no código (arquivo e commit)
  • Como verificou (teste ou execução)
  • O que descartou e por quê
Registro vago não vale: “perguntei à IA” sem prompt, resposta e verificação conta como uso não declarado. Se você não consegue explicar na arguição, não é seu. Código de IA copiado vale zero.
